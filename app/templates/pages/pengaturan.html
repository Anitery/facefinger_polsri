Validasi Jadwal

Saat aktif, mahasiswa hanya bisa akses saat ada jadwal KBM yang sesuai. Saat dimatikan, semua scan biometrik (mahasiswa/dosen) langsung berhasil tanpa cek jadwal — dan presensi otomatis tidak akan tercatat karena tidak ada jadwal untuk diacu.

Nonaktif berarti siapa saja bisa akses kapan saja tanpa jadwal. Presensi otomatis juga berhenti tercatat.
Privasi Alamat IP Perangkat

Saat aktif, IP address perangkat X606-S disembunyikan di dashboard untuk role selain admin/teknisi (diganti jadi status "Terhubung"/"—"). Admin dan teknisi tetap melihat IP asli untuk keperluan troubleshooting.

Mode Pemeliharaan

Saat aktif, semua akses biometrik ditolak kecuali admin & teknisi — berguna saat kalibrasi ulang device atau perbaikan sistem tanpa mengunci diri sendiri keluar.

Semua mahasiswa dan dosen akan ditolak aksesnya selama mode ini aktif.
Nonaktifkan Penghapusan Otomatis dari Alat (Semua Alat)

Sistem normalnya menghapus otomatis akses fisik user dari alat kalau jadwalnya sudah tidak ada lagi (lihat catatan "self-healing" di halaman Sync Biometrik). Saat toggle ini aktif, penghapusan otomatis itu dimatikan untuk SEMUA alat — data user di alat tidak akan terhapus lagi walau tidak ada jadwal, sampai toggle ini dimatikan kembali. User baru tetap bisa ditambah/dikirim seperti biasa; ini cuma mematikan proses "hapus"-nya saja.

Semua alat berhenti menghapus user otomatis walau jadwalnya sudah habis — pastikan ini memang disengaja.
Nonaktifkan Penghapusan Otomatis per Alat

Kalau cuma ingin mematikan penghapusan otomatis untuk 1 atau beberapa alat tertentu saja (bukan semua), pilih di bawah ini. Tidak berlaku kalau toggle "Semua Alat" di atas sedang aktif — toggle global selalu menang.

Toleransi Masuk Lebih Awal

Berapa menit sebelum jam mulai jadwal, alat sudah mengizinkan mahasiswa scan & masuk ruangan? Contoh: jadwal jam 15:00 dengan toleransi 15 menit → mahasiswa sudah bisa masuk sejak jam 14:45. Ini hanya memperlebar jendela akses, tidak mengubah status presensi (tetap dihitung dari jam mulai jadwal yang asli, bukan dari toleransi ini).
