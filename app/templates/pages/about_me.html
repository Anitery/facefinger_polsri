Smart Door Lock — Face & Fingerprint
Sistem Kontrol Akses Laboratorium Berbasis Biometrik

Proyek Tugas Akhir yang mengembangkan sistem kontrol akses laboratorium dengan memanfaatkan autentikasi biometrik, pengelolaan jadwal perkuliahan, pencatatan akses, dan manajemen pengguna secara terpusat.

Biometric Access Schedule Control Centralized Database Network Integration Access Logging
Tentang Sistem
Integrasi perangkat, jaringan, dan aplikasi

Sistem dirancang untuk menghubungkan perangkat akses pada masing-masing laboratorium dengan server lokal yang berada pada jaringan kampus. Setiap perangkat X606-S berkomunikasi melalui bridge berbasis STB/Armbian sebelum terhubung dengan aplikasi utama.

Aplikasi utama menyediakan pengelolaan data pengguna, ruangan, jadwal, presensi, serta pencatatan aktivitas akses. Dengan arsitektur tersebut, aktivitas dari beberapa laboratorium dapat dikelola melalui satu sistem terpusat.

Tujuan Pengembangan
Kontrol akses yang terintegrasi
01
Autentikasi pengguna

Memanfaatkan metode biometrik pada perangkat X606-S untuk melakukan verifikasi pengguna.

02
Kontrol berdasarkan jadwal

Data jadwal digunakan sebagai bagian dari pengaturan akses pengguna terhadap ruangan.

03
Pencatatan aktivitas

Setiap aktivitas akses dapat dicatat dan dikelola melalui sistem secara terpusat.

Teknologi
Komponen yang digunakan
Backend

FastAPI dan SQLAlchemy digunakan untuk membangun layanan aplikasi dan pengelolaan database.

Database

PostgreSQL digunakan sebagai basis data utama untuk menyimpan data sistem secara terpusat.

Server

Raspberry Pi digunakan sebagai server lokal yang menjalankan aplikasi pada jaringan kampus.

Bridge / STB

STB berbasis Armbian berfungsi sebagai bridge antara server dan perangkat X606-S.

Solution X606-S

Perangkat akses biometrik yang menangani autentikasi dan aktivitas akses pada laboratorium.

SOAP / XML

Digunakan sebagai protokol komunikasi dengan perangkat X606-S.

REST API

Menyediakan komunikasi antara aplikasi utama dengan service pada bridge.

Linux & Systemd

Digunakan untuk menjalankan service bridge dan door service secara otomatis.

Capaian Saat Ini & Rencana Pengembangan Selanjutnya

Hingga tahap ini, sistem Smart Door Lock telah berhasil dikembangkan dan mampu mengelola beberapa perangkat (multi-device) secara terpusat, mencakup sinkronisasi data fingerprint, pengaturan jadwal akses, pencatatan presensi, serta perekaman log akses pada setiap laboratorium yang terhubung. Pengelolaan data wajah pada sistem saat ini belum tersedia.

Proyek ini dikembangkan sebagai Tugas Akhir dan pengembangannya tidak dilanjutkan lebih jauh oleh pengembang. Namun, sistem ini masih memiliki beberapa kemungkinan pengembangan yang dapat dilanjutkan oleh pihak lain, seperti peningkatan optimasi performa aplikasi dan server, penambahan kemampuan untuk mengelola data wajah yang tersimpan pada perangkat, serta fitur input data fingerprint dan wajah secara langsung melalui website tanpa perlu melakukan pendaftaran manual pada perangkat.
